### [DriftGuard](https://github.com/Sean-Pereira-945/DriftGuard) &nbsp;[![PyPI](https://img.shields.io/pypi/v/driftguard-tokepi?style=flat-square&color=C9A96E&labelColor=111111&label=pypi)](https://pypi.org/project/driftguard-tokepi/)

**Observability for AI agents and LLM applications.**
When an agent keeps retrying a failing tool, you pay for every attempt. DriftGuard names the tool that's blocking the task, totals the wasted tokens, and raises an alert.

- Per-task diagnosis (blocked · failing · recovered · healthy) with drift scoring against a statistical baseline
- No-code **MCP gateway**, plus adapters for **LangChain**, the **OpenAI Agents SDK**, and the **Claude Agent SDK**
- Live dashboard over WebSockets, with alerts to Slack and webhooks
- Hardened with JWT sessions, rotatable API keys, rate limiting, and 220+ tests in CI

`pip install driftguard-tokepi`

<sub>Python · FastAPI · PostgreSQL · Redis · React · TypeScript · WebSockets · Docker</sub>
